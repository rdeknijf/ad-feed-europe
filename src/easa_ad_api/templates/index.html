What this is not

Not EASA

An unofficial mirror of data that EASA publishes. Not affiliated with or endorsed by EASA.

Not for compliance

The service does not judge whether an AD applies, and it does not match serial or part numbers. Always confirm against the official EASA publication.

Not always current

This server reads the interim page every 30 minutes. Each JSON response gives the last interim sync time and sets a stale flag when no interim sync has succeeded for {{ stale_hours | round(1) | replace(".0", "") }} hours.

Not a copy of the PDFs

Every record links to the EASA page that lists it, and to EASA's own document where EASA lists one. From each PDF header the server publishes only the dates, the supersedure and revision references, the foreign AD reference and the start of the applicability text (at most 300 characters).

Endpoints

Every JSON response carries a meta block with the notice, the last interim sync time and the stale flag. Atom feeds carry the notice and the stale warning. The OpenAPI documentation lists every parameter.

GET/v1/ads/{number}

One publication with types, links to the official documents, supersedure chain and status.

GET/v1/ads?type=&holder=&class=&issuer=&status=

Search by these parameters, or by subject text and issue or effective date.

GET/v1/types

Type designations with the number of publications for each.

GET/v1/types/{type}/ads

All publications listed for one type or model.

GET/v1/changes?since=&after_id=

New publications, status changes and new documents, paged by id.

GET/v1/changes.atom?type=&holder=&class=&issuer=

The same changes as an Atom feed. Emergency ADs carry an emergency category and title.

GET/v1/status

Last successful sync per source, the stale flag, counts and the CSV reconciliation result.

GET/docs

OpenAPI documentation with every parameter.

How type matching works

A type query matches the type and model names exactly as EASA lists them, without regard to case. The interim page gives a clean list per holder. The archive gives one line of names joined by "/", and some model names contain "/", so the split of archive rows is a guess and is marked parse_confidence: low. Use match=contains to search the type text as EASA published it.

curl '{{ example_url }}?status=active'
curl '{{ base }}/v1/ads?type=CFM56-7B&match=contains&class=EAD'

The status "active" means only that EASA's published data shows no supersedure, cancellation, withdrawal or revision for the AD. Whether it applies to an aircraft, or is in force, comes from the official EASA document.
